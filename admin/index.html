Bildirim Gönderimi

Expo Push API üzerinden kayıtlı mobil cihazlara anlık bildirim yayınlayın.

Yeni Bildirim Oluştur

Push Bildirim Rehberi

Bu arayüz, Expo'nun global anlık bildirim altyapısını kullanmaktadır. Sistemin çalışması için:

  1. Mobil kullanıcı uygulamanıza giriş yaptığında, cihazında oluşturulan Expo Push Token değeri otomatik olarak Supabase'e kaydedilmelidir.
  2. Admin paneli, kayıtlı tokenları doğrudan tarayıcı üzerinden Expo Push Gateway API'sine gönderir.
  3. Expo, Apple APNs ve Google FCM servisleri üzerinden bildirimi saniyeler içinde fiziksel cihazlara iletir.

SQL Migrasyon Bilgisi

Kullanıcıların tokenlarını kaydetmek için Supabase'de public.profiles tablosuna expo_push_token TEXT kolonunu eklemeniz gerekir.

E-Posta Bülteni

Kayıtlı kullanıcılara bültenler, duyurular veya özel mesajlar gönderin.

Yeni E-Posta Oluştur

Canlı Önizleme

E-Posta Gönderim Rehberi

Bu arayüz, e-postalarınızı doğrudan serverless Deno Edge Function üzerinden Resend API kullanarak gönderir.

  1. E-postaların gönderici adresi info@desivo.app olarak imzalanır.
  2. İçerik kısmında standart HTML etiketleri kullanarak bağlantılar (linkler), başlıklar veya kalın metinler oluşturabilirsiniz.
  3. Resend Ücretsiz Paket Limiti: Aylık 3.000 mail gönderimi dahildir (Günlük limit yoktur).

DNS Doğrulama Hatırlatması

Gönderilen maillerin doğrudan gelen kutusuna (inbox) düşmesi için resend.com üzerindeki DNS doğrulama adımlarını Hostinger panelinizde tamamlamış olmalısınız.

Sistem Duyurusu

Uzak Yapılandırma Kılavuzu

Bu panel, mobil uygulamanın veritabanındaki public.system_settings tablosunu günceller. Uygulama her açıldığında ve verileri yenilediğinde bu ayarları canlı olarak kontrol eder.

  • Limitler: Ücretsiz kullanıcıların günlük maksimum üretim limitleri ve AdMob ile kazanabilecekleri haftalık ek kredi izleme adetleri bu alandan anlık olarak kısıtlanabilir veya esnetilebilir.
  • Bakım Modu: Sunucu bakımı veya sürüm geçişi sırasında uygulamanın tüm işlevlerini kapatıp kullanıcıya bildirim ekranı göstermek için kullanılır.
  • Duyuru Kartı: Mobil uygulamanın ana sayfa paneline düşecek şık neon bir bilgilendirme penceresidir. Kapatıldığında cihaz hafızasında tutulur ve tekrar gösterilmez.
